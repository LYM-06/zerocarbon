# 🏭 大唐长春二热碳排放监测·预测·调度优化系统

基于 **2×660MW 超超临界热电联产项目** 的智能控碳系统，构建「监测-预测-优化」三级智能控碳体系。

## 项目简介

本系统以大唐长春二热「退城进郊」迁建项目为真实场景，实现：

- **实时碳监测**：基于烟气 CEMS 与物料计量数据，逐时核算全厂碳排放，动态展示排放结构
- **碳排放预测**：采用「机理模型 + 随机森林」融合算法，实现多工况下碳排放精准预测
- **调度优化**：以碳最小化为目标，优化机组负荷分配与热电耦合运行，量化减碳效果

## 方法说明

### 碳排放核算

严格遵循《企业温室气体排放核算方法与报告指南 发电设施》：

```
E_燃烧 = B × Q_net × C × O × (44/12)
```

- **B**：燃煤消耗量
- **Q_net**：标准煤低位发热量
- **C**：单位热值含碳量
- **O**：碳氧化率

包含**燃料燃烧排放**与**脱硫过程排放**两大项，热电分摊采用热量法。

### 预测模型

采用**机理驱动 + 数据修正**的混合预测框架：
- 底层：基于煤耗特性与排放因子构建物理机理模型
- 上层：随机森林算法拟合非线性波动（测试集 MAPE < 3%）

### 调度优化

以全厂碳排放最小化为目标的线性规划模型：
- **决策变量**：2 台机组的发电功率、抽汽量，调峰电锅炉出力
- **约束条件**：功率平衡、热负荷平衡、热电耦合运行约束、设备额定容量
- **求解算法**：单纯形法，保证全局最优解
